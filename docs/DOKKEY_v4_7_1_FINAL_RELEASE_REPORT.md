## 2. 상세 작업 내역

### [1] 앱 아이콘 및 웰컴 다이얼로그 캐릭터 그래픽 개선
1. **런처 앱 아이콘 최적화**
   - 어둡거나 덧칠된 느낌을 배제하고, 밝고 귀여운 황금빛 테마의 깨비 캐릭터 중심 런처 아이콘 세트(`mipmap-mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) 적용.
2. **첫 실행 웰컴 선물 다이얼로그 그래픽 복원**
   - 첫 설치/실행 시 노출되는 '깨비의 첫 만남 웰컴 선물!' 팝업에 가장 밝고 친근한 2번 페이스 에셋(`kkaebi_face_02.png`)을 적용하여 첫인상 호감도 극대화.

### [2] 상단 네비게이션 헤더 레이아웃 최적화
1. **로고-메뉴 분리 정렬**
   - 좌측: 깨비 심볼 아이콘 + `DOC-KEY` 브랜드 로고를 좌측 끝에 안정적으로 고정 배치.
   - 우측: `캘린더`, `만물상`, `99도감`, `설정`, `언어` 아이콘 메뉴들을 우측으로 균등 정렬하여 시각적 여백과 밸런스 확보.

### [3] 안드로이드 홈 화면 위젯 시인성 대폭 강화
1. **위젯 XML 레이아웃 타이포그래피 업그레이드** (`android/app/src/main/res/layout/kkaebi_quote_widget.xml`)
   - **깨비의 해석 영역 (`widget_kkaebi`)**: 기존 작은 글씨에서 **`15sp Bold`**로 대폭 확대.
   - **텍스트 컬러**: 배경 대비가 뛰어난 선명한 **골드 (`#FFE66D`)** 적용.
   - **행간 및 줄 수**: `lineSpacingMultiplier="1.25"`, `maxLines="3"` 설정으로 긴 해설도 가독성 있게 표현.
   - **명언 및 헤더**: 명언 본문 `16.5sp Bold Serif`, 헤더 `14sp Bold`로 정돈.

### [4] 3D 깨비 12회 터치 이스터에그: 1시간 고정 행운 번호(사다리 게임) 시스템
1. **인터랙션 단계별 연출** (`Kkaebi3DMascotWidget`, `QuoteHeroSection`)
   - **1~4회 터치**: 기쁨/호기심 모션 반응.
   - **5회 터치**: **1차 분노 지진 흔들림 효과** (`ScreenEmotionFxOverlay.show(..., EmotionType.rage)`).
   - **6~9회 터치**: 호기심/불꽃/부끄 모션 연출.
   - **10회 터치**: **2차 분노 지진 흔들림 효과** (화면 균열/진동).
   - **11회 터치**: 놀람 모션 예고.
   - **12회 터치**: **연금술 효과음 + 강한 햅틱 진동 + 전체 화면 0~9 랜덤 행운 번호 모달 팝업** 발생.
2. **1시간 고정 결정론적 로직 (`KkaebiEasterEggService`)**
   - 시간대 슬롯 키 (`yyyy_M_d_H`)를 기반으로 기기별로 1시간(`HH:00 ~ HH:59`) 동안 0~9 사이의 난수 1개가 고정 저장됨.
   - 친구/동료와 모임 시 각자 스마트폰으로 깨비를 12번 터치해 나온 숫자로 순번 정하기, 밥값 내기, 사다리 게임 대체 용도로 활용 가능.
   - 매 시간 정각(`00분`)이 되면 새로운 숫자로 자동 갱신.

### [5] 이스터에그 모달창 가독성 및 UI/UX 강화
1. **헤더 및 닫기 버튼 최적화** (`lib/widgets/kkaebi_easter_egg_dialog.dart`)
   - 상단 타이틀 바에 고급스러운 황금 그라데이션 및 명확한 뱃지 적용.
   - 우측 상단 닫기 `[X]` 버튼을 **직경 38dp, 두께 1.8px 황금 테두리, 고대비 밝은 골드 아이콘**으로 리디자인하여 한눈에 식별 가능하도록 개선.
2. **모달 본문 연출**
   - 화면 중앙에 **115px 초대형 골드 펄스 숫자** 출력.
   - 하단에 "이 숫자는 1시간 동안 고정되어 친구들과 사다리/내기 게임에 사용할 수 있어!" 안내 및 남은 시간(분) 실시간 카운트다운 표시.

### [6] 6개 언어 완벽 다국어 지원 (Localization)
- 한국어(`ko`), 영어(`en`), 일본어(`ja`), 중국어(`zh`), 힌디어(`hi`), 독일어(`de`)의 6개 언어별 번역 사전 구축:
  - 다이얼로그 타이틀
  - 기능 설명 문구
  - 1시간 고정 안내
  - 남은 유효 시간 표기
  - 닫기 버튼
- 앱 내 언어 변경 시 즉각적으로 해당 언어로 동기화.
